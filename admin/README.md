# TAREH Admin Dashboard

Reserved for the responsive web administration application.

Planned stack:
- React
- TypeScript
- Vite
- Backend-enforced role-based access control
- Arabic RTL first

Planned areas: overview, users, competitions, teams, matches, result review, provider sync health, notifications, reports and audit logs.

Never rely on UI visibility alone for authorization. Every protected action must be checked by the API.

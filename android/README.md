# TAREH Android

Reserved for the consumer Android app.

Planned stack:
- Kotlin
- Jetpack Compose
- Material 3
- MVVM + Clean Architecture
- Retrofit or Ktor Client
- Hilt
- Room for selected offline cache use cases

The app is Arabic-first and RTL. It must show cached football data with a clear last-updated timestamp when connectivity is unavailable.

Release scope is a free football companion and free predictions using non-monetary points only.

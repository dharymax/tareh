# طارح | TAREH

منصة عربية لمتابعة كرة القدم والتوقعات الرياضية المجانية.

> الإصدار الأول مخصص للنتائج والمباريات والإحصائيات والتوقعات بنظام نقاط افتراضي غير قابل للتحويل إلى أموال. لا يتضمن مراهنات مالية أو إيداعاً أو سحباً.

## مواصفات المنتج
- السوق الأولي: اليمن
- اللغة: العربية (RTL)
- Android: Kotlin + Jetpack Compose
- لوحة الإدارة: React + TypeScript + Vite
- Backend: NestJS + TypeScript
- قاعدة البيانات: PostgreSQL + Prisma
- Cache / Realtime: Redis + WebSocket

## هيكل المستودع
- `android/` تطبيق Android
- `backend/` واجهة API والخدمات
- `admin/` لوحة الإدارة
- `infrastructure/` ملفات النشر والتشغيل
- `docs/` الوثائق الفنية
